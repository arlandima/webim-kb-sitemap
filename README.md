# Webim AI Knowledge

Независимый прототип «Базы знаний нового поколения» для публичной документации Webim ([webim.ru/kb](https://webim.ru/kb/)).
Пользователь задаёт вопрос обычными словами → гибридный поиск находит нужные разделы → ответ собирается **только** из найденных фрагментов → рядом показаны источники со ссылками на оригинальный раздел на webim.ru (с точным якорем).

Оригинальный сайт и База знаний **не изменяются**: приложение только читает публичные страницы.

## Запуск (одна команда)

Нужен Python 3.10+ и интернет при первом запуске (зависимости + модели ≈ 2,8 ГБ, один раз).

```bash
python run.py          # Windows: start.bat   macOS/Linux: ./start.sh
```

Откроется http://localhost:8000. Индекс реальной Базы знаний уже лежит в репозитории (`data/index.sqlite`), пересобирать ничего не нужно.
API-ключи **не требуются**: без LLM работает поиск и «извлекающий» ответ из документации.

| Адрес | Что это |
|---|---|
| `/` | вопрос → ответ + источники + релевантные статьи |
| `/demo` | 10 проверенных сценариев для показа (+ пример корректного отказа) |
| `/browse` | обзор документации по дереву разделов |
| `/admin` | статус индекса, модели, история синхронизаций |
| `/api/docs` | Swagger API |

## Что реализовано

| Возможность | Статус |
|---|---|
| Краулер `webim.ru/kb` (sitemap + ссылки, только `/kb/`, кэш, условные запросы, ограничение частоты) | ✅ |
| Разбор MkDocs-страниц: заголовки H1–H4, якоря, хлебные крошки, списки, таблицы, код, даты | ✅ |
| Секционное разбиение с сохранением пути заголовков и якоря (provenance) | ✅ |
| Инкрементальная синхронизация (`python -m webim_ai.sync`) — новые/изменённые/удалённые страницы | ✅ |
| Гибридный поиск: FTS5/BM25 по стеммам + эмбеддинги чанков + эмбеддинги заголовков → RRF | ✅ |
| Реранкер (bge-reranker-v2-m3, ONNX) | ✅ |
| Ответ по доказательствам, цитаты `[n]`, защита от инъекций, отказ «недостаточно информации» | ✅ |
| LLM: любой OpenAI-совместимый сервер, опционально Anthropic; стриминг | ✅ (проверено на тестовом сервере; на реальной модели — не проверялось) |
| Режим без LLM: извлекающий ответ из найденных фрагментов | ✅ |
| Интерфейс в стиле Webim: главная, результаты, инспектор источников, обзор, демо, статус | ✅ |
| Фильтр «Искать в» (раздел документации) для неоднозначных вопросов | ✅ |
| Диалог с уточняющими вопросами (контекст только для поиска и промпта) | ⚠️ базовый |
| Ночная синхронизация по расписанию | ⚠️ команда есть, планировщик — инструкция в `docs/INDEXING.md` |
| Авторизация, мультитенантность, свои источники (PDF/DOCX/…) | 🔮 дорожная карта |

Метрики качества поиска на 46 вопросах — в [`FINAL_REPORT.md`](FINAL_REPORT.md) и `eval/results.json`.

## Команды

```bash
python run.py --sync                 # обновить индекс с сайта и запустить
python -m webim_ai.sync              # только синхронизация (быстро, если ничего не менялось)
python -m webim_ai.sync --force      # перекачать всё
python -m pytest tests -q            # тесты (в т.ч. браузерные, нужен Chromium: pip install -r requirements-dev.txt)
python eval/run_eval.py --compare    # оценка поиска: лексика / гибрид / гибрид+реранкер
python eval/verify_demo.py           # проверка демо-сценариев на живом индексе
python eval/check_links.py --live    # проверка якорей и живых ссылок на источники
python scripts/check_llm.py          # проверка подключения LLM
```

## Структура

```
webim_ai/   crawler.py parser.py chunker.py store.py sync.py models.py retrieval.py answer.py server.py
web/        интерфейс (HTML/CSS/JS без сборки), шрифты Roboto и логотип Webim с webim.ru
eval/       вопросы для оценки, демо-сценарии, скрипты проверки
tests/      pytest: краулер, парсер, индекс, поиск, ответы, API, браузерный UI
data/       index.sqlite (индекс с эмбеддингами), cache/ и models/ — не в Git
```

Логотип, шрифты и цвета взяты с публичных страниц webim.ru для внутреннего прототипа; права на них принадлежат Webim.
