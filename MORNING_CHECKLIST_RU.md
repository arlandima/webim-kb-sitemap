# Утренний чек-лист (10 шагов)

1. **Ветка с готовой работой:** `claude/webim-ai-knowledge-fx8wti` (репозиторий `arlandima/webim-kb-sitemap`).
2. **Получить код:**
   ```
   git clone -b claude/webim-ai-knowledge-fx8wti https://github.com/arlandima/webim-kb-sitemap.git
   cd webim-kb-sitemap
   ```
   (если репозиторий уже склонирован: `git fetch origin && git checkout claude/webim-ai-knowledge-fx8wti && git pull`)
3. **Что нужно заранее:** Python 3.10+ (проверка: `python --version`), интернет, ≈ 4 ГБ свободного места. Ничего больше ставить не нужно. На Windows при установке Python отметьте «Add python.exe to PATH».
4. **Установка** — отдельной команды нет, всё делает запуск: при первом старте создаётся папка `.venv`, ставятся зависимости (1–3 мин) и скачиваются модели поиска (≈ 2,8 ГБ, 3–10 мин, один раз). Индекс уже в репозитории (`data/index.sqlite`).
5. **Запуск (одна команда):**
   - Windows: `start.bat` (или `python run.py`)
   - macOS/Linux: `./start.sh` (или `python3 run.py`)

   Дождитесь строки «✔ Webim AI Knowledge: http://localhost:8000».
6. **Адрес в браузере:** http://localhost:8000 (примеры — `/demo`, статус — `/admin`). Браузер откроется сам.
7. **Нужен ли API-ключ:** **нет.** Ни для поиска, ни для запуска. Интернет нужен только для первого запуска и для кнопок «Открыть оригинал» (ведут на webim.ru).
8. **Пять лучших вопросов для показа** (все проверены `python eval/verify_demo.py`):
   1. Как сделать, чтобы клиент сначала написал вопрос, а чат создавался потом?
   2. Как оставить в диалоге заметку, которую клиент не увидит?
   3. Почему мне не приходят звуковые уведомления о новых сообщениях?
   4. `password_hashers` (точное имя параметра) — и `how to configure S3 storage for chat files` (вопрос по-английски)
   5. Как подключить интеграцию с Bitrix24? (в документации нет — честный отказ)

   Пошаговый сценарий на 5 минут — `docs/DEMO_GUIDE.md`. Перед показом задайте один «разогревочный» вопрос.
9. **Что работает без языковой модели:** всё, кроме связного пересказа: поиск по смыслу и по точным терминам, реранкинг, «выдержки из документации» вместо пересказа, источники с точными якорями, инспектор источников, отказ «недостаточно информации», обзор документации, демо, статус. Ответ без LLM собирается из реальных предложений документации — ничего не выдумано.
10. **Подключить локальную LLM позже:** скопируйте `.env.example` в `.env`, заполните три строки и перезапустите:
    ```
    LLM_BASE_URL=http://localhost:1234/v1     # LM Studio; для vLLM обычно http://localhost:8001/v1
    LLM_API_KEY=local
    LLM_MODEL=<имя модели как в LM Studio/vLLM>
    ```
    Проверка: `python scripts/check_llm.py`. Подробно для RTX 5090 и Mac Studio — `docs/LOCAL_LLM.md`. Обновить данные с сайта: `python run.py --sync`.

**Если что-то не так:** поиск отвечает 2–3 с — это нормально на CPU (реранкер). Не скачались модели — приложение запустится в упрощённом режиме (только лексический поиск), повторите запуск при интернете. Полный отчёт и известные ограничения — `FINAL_REPORT.md`.
