# Дорожная карта

Всё ниже — **идеи развития**, а не существующие функции. Что уже реализовано — см. README.

## Ближайшие шаги (доработка прототипа)

1. Замер на реальной LLM (vLLM/LM Studio/MLX): качество формулировок, доля отказов, время до первого токена; подбор модели.
2. Расширить оценочный набор до 150–200 вопросов из реальных обращений в поддержку (сейчас 46, составлены разработчиком) и держать его как регрессионный тест.
3. Ускорение реранкера (GPU, меньше кандидатов, distillation) — сейчас ≈ 2,5 с на CPU.
4. Горячая перезагрузка индекса после ночной синхронизации; расписание в самом сервисе.
5. Обратная связь «помог / не помог» и журнал вопросов без ответа → список пробелов документации для авторов Базы знаний.
6. Улучшение частных случаев: синонимы предметной области, вопросы «на обходной путь» (например, «передать чат» ↔ «переадресация»).

## Возможности как продукта Webim AI Knowledge (идеи)

Поток:

```
вопрос клиента → гибридный поиск → реранкинг → ответ по источникам
              → оценка уверенности → ответ  ИЛИ  передача оператору
```

* **Источники знаний клиента:** сайт клиента, PDF, DOCX, FAQ, Confluence, Notion, внутренняя документация. Те же принципы: секционное разбиение, provenance, инкрементальная синхронизация; отдельный индекс на клиента.
* **Оценка уверенности и эскалация:** если доказательств недостаточно — предложить позвать оператора (с передачей найденных фрагментов оператору как подсказки).
* **Подсказки оператору внутри РМО:** те же ответы с источниками как «суфлёр» (в Webim уже есть направление «Суфлёры» — интеграция потребует отдельного проектирования).
* **Каналы:** виджет чата и мессенджеры, поддерживаемые Webim, — по мере технической возможности; текущих интеграций прототип **не имеет**.
* **Многоязычность, разграничение доступа к документам, аудит ответов, аналитика пробелов знаний.**
* **Развёртывание:** облако Webim или on-premise рядом с клиентом (локальная модель), выбор модели под требования к данным.

Сроки и объём не оцениваются: требуется пилот с реальными данными клиента.
